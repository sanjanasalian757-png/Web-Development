# 🎮 Game of Shapes

A mini frontend project built to practice CSS positioning, basic geometric layout shapes, and hover animations.

## 🚀 Features
* **Interactive Elements:** Features three primary shapes (Square, Diamond, and Circle) that respond dynamically when a user hovers over them.
* **Layout Practice:** Uses CSS Flexbox for structure and specific 2D transforms (rotation and translation) to construct the diamond layout.

## 🛠️ Tech Stack
* HTML5
* CSS3

## 📸 Preview
* **Shape 1 (Square):** Changes its background color to red on hover.
* **Shape 2 (Diamond):** Tilted at 45 degrees, shifts positions slightly, and turns blue on hover.
* **Shape 3 (Circle):** Styled with a 50% border radius and turns green on hover.

## 📝 How to Run Locally
1. Clone this repository.
2. Navigate into the `game-of-shapes` folder.
3. Open `index.html` directly in any web browser.
