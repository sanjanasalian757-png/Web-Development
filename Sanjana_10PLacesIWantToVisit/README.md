# 10 Places I Want to Visit 🌍

A simple HTML and CSS project showcasing **10 travel destinations I would love to visit someday**.

## 📌 About the Project

This project was created using **HTML and CSS** as part of my web development practice. It presents a list of 10 dream travel destinations along with a short description and an image for each place.

The project focuses on practicing:

* HTML page structure
* Headings and paragraphs
* Images and alternative text
* HTML sections and footer
* CSS styling
* Hover effects
* Colors, borders, spacing, and typography

## ✈️ Destinations

1. 🇫🇷 **Paris, France**
2. 🇯🇵 **Kyoto, Japan**
3. 🇬🇷 **Santorini, Greece**
4. 🇵🇪 **Machu Picchu, Peru**
5. 🇦🇺 **Sydney, Australia**
6. 🇮🇹 **Rome, Italy**
7. 🇮🇩 **Bali, Indonesia**
8. 🇺🇸 **New York City, USA**
9. 🇿🇦 **Cape Town, South Africa**
10. 🇧🇷 **Rio de Janeiro, Brazil**

* Clean and simple travel-themed webpage
* Individual section for each destination
* Destination images with descriptive `alt` text
* Hover effects on headings, paragraphs, and images
* Styled header and footer
* Responsive viewport configuration for different screen sizes

## 🚀 How to Run

1. Clone or download this repository.
2. Open the `Sanjana_10PLacesIWantToVisit` folder.
3. Open `index.html` in any web browser.
4. Explore the 10 destinations!
